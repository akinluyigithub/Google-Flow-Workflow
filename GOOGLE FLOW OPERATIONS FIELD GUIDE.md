# Google Flow Operations Field Guide

Practical operating knowledge distilled from Google's current Flow Help Center for this workflow. Use with [system prompt.md](system%20prompt.md), [UNIVERSAL VIRAL VIDEO WORKFLOW.md](UNIVERSAL%20VIRAL%20VIDEO%20WORKFLOW.md), [video editing prompt.md](video%20editing%20prompt.md), and [Google Flow Character and Voice Guide](GOOGLE%20FLOW%20CHARACTER%20AND%20VOICE%20GUIDE.md).

Google Flow changes quickly. Treat the live model picker, generation settings, displayed credit cost, account/region availability, and current official Help pages as authoritative. This guide records operational patterns; it deliberately avoids hard-coding credit prices and volatile availability.

## 1. Access and workspace basics

- Flow's most complete editing experience is on desktop in a Chromium browser such as Chrome or Edge. Google's Agent and custom Tools are documented for web/PC. Mobile access exists, but some desktop capabilities are not available there.
- Access depends on age, supported region, subscription/account eligibility, and feature rollout. Check Google's current region/eligibility page when access or a feature is missing; a VPN does not unlock unsupported regions.
- Start from the project where the work belongs. Agent sessions and generated media are project-specific: media generated by the Agent is automatically saved into the currently open project.
- The prompt box changes when **Agent** is switched on. Use the Agent for conversational planning, prompt refinement, generation, edits, batches, and organization; switch it off for the standard prompt-box model/mode controls.
- Agent text queries do not currently use Flow credits, but daily Agent query and Tool creation quotas exist. Generated images, videos, and media from Tools use credits.

## 2. Separate project settings, Agent settings, and generation settings

These controls serve different purposes; check the right layer before work:

1. **Project display settings** (top-right project Settings): asset view (Grid/Batch), grid size, sound on hover, silent-video behavior, tile details, and whether to clear prompt/references after submission.
2. **Agent defaults** (Agent Settings beneath prompt box): confirmation before credit-using generations; default image aspect ratio/model/output count; default video orientation/model/output count. The current user's established preference is `Always confirm` as the protective setting. Honor explicit per-batch image authorization operationally, but never bypass the separate explicit approval for paid video generation.
3. **Per-generation settings** (model/mode and generation preferences): active model, aspect/orientation, output count, duration, resolution/draft setting, and selected references. Confirm these for each generation because defaults, model support, and cost can differ.

Project display settings do not set the image or video model. An Agent default is not proof that the current generation uses that model. Inspect the controls at the prompt before submission.

## 3. Credits and generation protection

- Credit balances are shared across devices on the Google account. Check the profile menu for remaining credits; eligible subscribers can inspect credit activity. Credit allowances and refreshes depend on plan and current policy.
- Costs depend on model, mode, duration, and output count. Google's Help states the cost table is per generation, not per request; a single request that returns multiple outputs may spend for each output. Read the live cost adjacent to the actual generation controls before acting. Do not quote saved static costs as current.
- The Flow Agent can plan without spending generation credits, but a request to generate/edit media does use credits. Batch prompts may create multiple separately chargeable assets.
- **This user's authorization rule:** for images, ask once for the provider. That choice authorizes the planned still-image prompt set in the approved production package; produce and inspect it, retry clear defects autonomously, and present results together for selection. Do not ask again about batch size, individual prompts, or results. For each video render/edit/extension that generates media, show the exact prompt, active model/mode, references, orientation/aspect, duration, output count, and live displayed cost, then stop for explicit clip-specific approval. A global Agent confirmation setting is not a substitute for the video approval gate.
- When a selected feature is unsupported by a model, Flow may switch to a compatible model or show an error. Recheck the actual active model, supported mode, and cost after any compatibility change and before generating.
- Generation can be rate-limited. If results are missing, refresh the project before retrying. For persistent Pending/error cards, inspect Flow notifications and error text. Google's Help says failed generations are not charged, but verify the account's activity if a credit discrepancy appears; report the problem through Flow/Google One support where applicable.

## 4. Prompting and references

- For images, describe the intended subject, visual details, composition, environment, lighting, style, and important exclusions. For videos, give a clear subject and one principal action, location/time, framing, one coherent camera behavior, lighting/palette, style, motion, continuity, and audio/dialogue. Fit all movement and speech to the selected duration.
- Use English prompts for best results per Google's current guidance; Flow supports many other languages, with quality potentially varying by language and prompt complexity.
- References should be clean and mutually compatible. Use plain/segmented backgrounds for subject/product references where useful, avoid unintended people or objects in location/style plates, and explicitly state which reference controls identity, location, prop, or style. Prompt text should complement—not contradict—the reference assets.
- `@CharacterName` references a saved project Character when supported. Describe how it should be used. A reusable Character or ingredient guides continuity; inspect results rather than promising exact identity continuity.
- To add a project asset to the prompt, use its More menu → **Add to Prompt**, type `@` and select the exact saved asset by name, use the **Add Image** control, or drag the approved media from the project/device into the prompt when available. For Agent image creation, current desktop Help explicitly documents drag-and-drop of media from the project or device. State the role of each attached item (identity, location, prop, style, or composition) in the prompt, then verify the selected thumbnail is the approved version before generating. Use names through the live `@` picker; do not assume a raw asset ID can be entered as prompt syntax. IDs are useful in the tracking ledger to distinguish similarly named versions. To reuse an older edit version, first **Save to Project** from History, then attach that saved version.
- A start/end frame is a visual endpoint input, not just text in the prompt. Use the actual Frames controls and describe the transition between them. Confirm the selected model supports the frame combination and duration.
- For character voice design and explicitly adding voice references, use the linked Character and Voice Guide. Current voice-reference support is mode-limited.

## 5. Images and image edits

- Image generation can run through the Agent or standard prompt box. The Agent can route a request to an image model and make multiple variations. The standard box lets you select model, aspect ratio, and output count. Never assume the default model: the documented default can vary by account tier and can change.
- For this user's workflow, choose ChatGPT Images or Google Flow Images once per image batch; use 9:16 for vertical social by default, and Nano Banana 2.1 for Flow images when available unless the user selects another model. Default to one output per distinct prompt, while submitting the different planned prompts together as a batch when supported.
- Review every image for prompt match, identity/reference adherence, physical plausibility, anatomy, object/hand/device geometry, location and prop placement, composition, aspect ratio, and relation to neighboring frames. If a specific object is impossible (for example, front and back surfaces of one phone visible at once), reject that candidate and retry with a constraint that fixes only the defect.
- Flow Agent image edits preserve the original in History/asset stack. You can select one or multiple images for an edit prompt. Use narrow edits that clearly state what changes and what stays fixed. Crop is available in image edit view. Compare versions and save the intended earlier version to the project before reusing it.
- Agent-generated batch results appear as individual tiles for flexible sorting; select multiple assets with Shift-click or a drag selection, and create Collections when needed. Do not expect a single group tile for each Agent request.

## 6. Video modes and model matching

Choose the mode based on the actual input and supported model:

- **Text to Video:** create a new shot from description.
- **Frames to Video:** animate a still/start frame or define first and last frames; describe the action/transition between them.
- **Ingredients/References to Video:** use subject/object/location/style assets as references. Voice references currently require supported Omni Flash video with Ingredients.
- **Video to Video / video edit:** modify an uploaded or generated clip with a text prompt and optional ingredients, when the model and region support it.
- **Extend:** add footage to the end of a compatible generated clip. Current Google documentation specifies Veo-generated inputs for Extend; check the live compatibility list. Some extended clips cannot later use insert/remove/camera edit modes.

Do not rely on a remembered model matrix. Google currently lists different support for Veo 3.1 Lite/Fast/Quality and Gemini Omni Flash 1.1: aspect ratios, durations, first/last frames, ingredients, editing, and Extend vary. The picker may auto-switch or reject an unsupported combination. Recheck [Models and supported features](https://support.google.com/flow/answer/16352836?hl=en) for the current project and account, and verify actual settings/cost before approval.

## 7. Editing, versioning, and assembling

### Local project handoff

- When the story and working title are approved, create a named project folder in the active Google-Flow workspace immediately. Keep story notes/prompts, references, approved Flow downloads, captions/audio, editor working files, and final exports together in subfolders; record the path in Project State.
- Download each approved source clip and the ready Scenebuilder scene into that project's Flow-downloads folder. Check that each file opens and matches the expected clip/sequence before editing further. Preserve originals.
- Treat this as the Phase 11 entry gate: once all approved video clips are ready, download and verify them together, then begin editing in the same project chat. Start HyperFrames only after those source files are present; no extra planning interview is needed.
- Resume the same production in its existing chat; when a new chat is needed, reuse the same workspace and local project folder rather than creating a duplicate.
- Keep project media local by default. The public workflow repository should contain reusable guidance, not private references or generated production assets, unless the user explicitly asks to publish those assets.

- Standard video edits do not remove the original; History retains previous versions and prompts. Agent edits are automatically saved into the asset stack. Compare versions and preserve the intended take.
- Current Google Help documents Gemini Omni Flash editing in supported regions: video input up to 60 seconds/1 GB in listed formats; clips longer than 30 seconds must be trimmed to 30 seconds; edit a selected segment up to 10 seconds; up to three follow-up turns may retain context. Verify these limits in Help and the live editor before starting because rollout can change.
- Save an approved earlier edited-video version to the project from History before placing it in Scenebuilder.
- Save a paused video frame as an image asset when it is needed as a future ingredient/start/end frame. Verify the saved frame appears in project assets.
- **Scenebuilder** assembles multiple clips in a sequence, reorders them, trims the beginning/end with handles, previews the whole sequence, and downloads a scene. It is not a full nonlinear editor for every advanced audio, graphics, or frame-accurate task.
- Direct YouTube publishing currently supports individual clips. For a full Scenebuilder sequence, download it as one file and upload via YouTube Studio. Publishing is a separate user-authorized action.
- Do not delete originals or assets while iterating. Deleting an Agent session clears that chat history but leaves media in project assets. Collection organization is safer for curation than deletion.

## 8. Project organization, sharing, and backup

- **Provider-aware storage:** Flow-generated stills remain in the same Flow project for labeling, review, and reuse as ingredients/frames. No workspace download or download-only upscale is needed before Flow video generation. Track Flow titles/URLs/IDs and status; local image paths are optional unless a requested export/backup or external task requires them. Save/copy ChatGPT-generated files into the project folder when accessible, upload them to Flow, and verify the result. Required Phase 11 video downloads are unaffected. Apply free upscale/export preferences only when an export is needed.

- **Free upscale default for necessary exports:** use the highest supported download resolution with no added money or credit cost and no plan upgrade. Prefer free 2K image upscaling over 1K-only delivery when offered. Verify live cost evidence and actual file dimensions, inspect fidelity after upscaling, retain useful originals, and record native/upscaled status in the ledger. The user's standing preference authorizes free upscaling without another question; paid options and unclear costs do not count as free. Apply this to supported free video exports too, preserving paid generation approval requirements.

- **Mandatory naming before review:** rename each completed/imported asset using the actual Flow title field and verify it saved. Use `REF 01 — Description`, `SHOT 01 — Story beat`, and `CLIP 01 — Story beat — v01`; captured UI screenshots use `SCREENSHOT 01 — Purpose`. Preserve identifiers in versions, feedback, downloads, and the local asset ledger. See [Asset Naming and Review Guide](ASSET%20NAMING%20AND%20REVIEW%20GUIDE.md). Do not present a batch as ready with unexplained automatic titles. Names identify story order even when Flow sorts tiles by recent activity.

- Project Settings can show generation prompt/type in tiles and switch between Grid and Batch views. Use descriptive project/asset names and nested Collections for characters, locations, selected frames, approved clips, and alternates.
- Project operations documented by Flow include search/filter, moving assets to trash, download, sharing, and export. A shared creation link can allow anyone with the link to find/use it; verify sharing scope before sharing.
- A Google Takeout Flow export may include generated/uploaded media, prompts, model and generation settings, voice configurations, trim offsets, projects, collections, characters, scenes, and edit stacks. Metadata JSON pairs map media IDs back to project/collection titles. Export is a backup copy; it does not delete server data.
- Agent sessions are project-specific and can be reopened/renamed. Deleting a session clears conversation history, not generated assets. Save important decisions in the Project State/series bible as well as the Agent conversation.
- Flow **Tools** are optional reusable mini-apps built from natural-language specifications in **Tools → Create Tool**; review the generated interface and choose Save to keep it. A tool that generates media spends credits and Flow displays a warning. Treat shared Tool links as public: anyone with the link can see the Tool's code/name/thumbnail, and a shared link is a snapshot that does not include later edits.

## 9. Privacy, safety, and provenance

- Google's current data notice says that when **Help improve Google Flow** is enabled, interactions, uploads, generated output, feature usage, and feedback may be used to improve products and reviewed by trained reviewers. Do not put confidential information or material you would not want reviewed into Flow. The setting can be switched off in Flow's More menu.
- Use only appropriate rights/consent for real-person references. Follow current Google content policies; Flow may block certain requests. The current region/help policy includes restrictions on generated videos of prominent people and editing uploaded videos of identifiable minors; feature-specific rules vary by region.
- Outputs from Veo, Omni, and Nano Banana include invisible SynthID. A visible watermark may be controlled in profile settings, and some locations/plan types may have it applied automatically. Do not try to remove provenance markings.
- If the user requests their own likeness, Flow has an optional protected Avatar feature: setup starts on desktop from profile → Create avatar and is completed on a phone/tablet using a QR flow; then the user can reference it with `@me`. It is region-limited, avatar data cannot be shared through Flow Tools or public project links, and it has additional likeness/safety checks. Do not create or use an avatar without the user's request and follow the live consent flow.
- Before publishing, verify platform terms, rights, required disclosure, and current upload requirements. Do not claim generated material has no AI provenance.

## 10. Troubleshooting routine

1. Identify whether the failure is an unsupported model/mode, content policy, region/rollout, credit shortage, rate limit, pending generation, upload format, or UI issue.
2. Read the exact live notification/error. Confirm active project and model/mode, refresh if an expected tile is missing, and wait/retry only when the error guidance supports it.
3. For policy or safety blocks, revise toward a compliant prompt; do not try to evade safety systems. Use **Flag output** for offensive results or **Send app feedback** with a screenshot for product bugs.
4. For access issues, check supported regions and account eligibility; Google's Help says VPNs do not enable an unsupported region.
5. For confusing credit deductions, compare the live cost and account credit activity; contact Google One/Flow support if the accounting appears incorrect.

## 11. Useful Windows shortcuts

Check the current platform-specific shortcut page for Mac/Linux updates. Google's current Windows list includes:

- `@` opens the prompt box menu; use it for asset/character references.
- `Space` previews/opens a grid asset; `Enter` opens Edit View.
- `Ctrl+D` downloads in Edit View/Grid; `Ctrl+U` uploads in Grid.
- `Ctrl+G` groups selected assets into a Collection.
- `Shift+G` toggles Grid view; `Shift+I` filters images; `Shift+V` filters videos; `Shift+U` filters uploads.
- Arrow keys move through assets/history in supported views; `Esc` closes Edit View/returns focus.
