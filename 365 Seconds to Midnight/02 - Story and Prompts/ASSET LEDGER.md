### Standing generation gate learned from this production

For every still: (1) make a shot-specific checklist of visible saved Characters, exact location plate/layout, salient recurring props and preceding approved frame when continuity requires it; (2) attach the real Flow assets and verify each displayed thumbnail/name and its role; (3) inspect Agent's final rewritten prompt and actual ingredient mapping if Agent mode is used; (4) generate; (5) inspect the resulting image against the exact prompt and references; (6) rename and verify the actual Flow tile immediately; and (7) record title, URL/asset ID, version, prompt, attached inputs, review status and local path if downloaded. Prompt text and Agent claims do not replace actual attachments. If the Agent's attachments cannot be verified, use the standard composer. Preserve the in-app browser on the active project and continue the ordered checklist without avoidable pauses. Generation success, visual QC and user approval are distinct states.
